================================================================================
SIMPLE COPY & PASTE DEPLOYMENT (Like Your Other Projects!)
================================================================================

YOU SAID: "In my other projects, I just copy the build folder and paste it
          to IIS server and it works perfectly"

THIS PROJECT: Almost the same! Just ONE extra step (because of database ORM)


THE SIMPLE WAY (3 COMMANDS)
================================================================================

On Development Machine:
-----------------------
cd C:\Users\ranaw\source\repos\MunshiJee
create-deployment-package.bat

This creates a folder called: deployment-package\


Copy to IIS Server:
-------------------
Copy: C:\Users\ranaw\source\repos\MunshiJee\deployment-package\
To:   C:\inetpub\wwwroot\munshijee.ideageek.pk\


On IIS Server:
--------------
cd C:\inetpub\wwwroot\munshijee.ideageek.pk
setup-production.bat

Then:
  1. Rename .env.example to .env
  2. Edit .env (add your database password)
  3. npm start

Done! Opens at http://localhost:3000


WHY THE EXTRA STEP?
================================================================================

Your other projects: Just static files
This project: Has Prisma ORM (needs database client generation)

The setup-production.bat does:
  1. npm install (like you'd do anyway)
  2. npx prisma generate (generate database client - ONE TIME)

After setup, updates are just: copy → npm start (like your other projects!)


WHAT'S IN THE PACKAGE?
================================================================================

deployment-package/
├── .next/                  ← Build output (like your other projects)
├── public/                 ← Static files (like your other projects)
├── package.json            ← Dependencies (like your other projects)
├── src/prisma/             ← NEW: Database schema
├── setup-production.bat    ← NEW: Run once to setup
├── .env.example            ← NEW: Configuration template
└── dbeaver-setup.sql       ← NEW: Database tables

Everything else is the same as your other projects!


DATABASE SETUP (DO THIS ONCE)
================================================================================

You said you created the database manually. You need to create tables:

1. Open DBeaver
2. Connect to your PostgreSQL database  
3. Open: dbeaver-setup.sql (from deployment package)
4. Execute it

This creates:
  - All tables
  - Super admin account (superadmin@munshijee.ideageek.pk / admin123!@#)
  - 5 subscription plans

TROUBLESHOOTING
================================================================================

"npm start doesn't work":
  → Did you run setup-production.bat?
  → Is .env file created and configured?

"Database connection failed":
  → Check DATABASE_URL in .env
  → Did you run dbeaver-setup.sql?

"Missing module errors":
  → Run: npm install
