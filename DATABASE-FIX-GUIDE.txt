DATABASE ERROR FIX - "Table public.User does not exist"
================================================================================

ERROR MESSAGE:
  "The table `public.User` does not exist in the current database"

CAUSE:
  Prisma can't find the database tables. This happens when:
  1. Tables weren't created (dbeaver-setup.sql not run)
  2. DATABASE_URL points to wrong database
  3. Prisma client is stale/outdated


QUICK FIX (3 Steps)
================================================================================

Step 1: Verify Your DATABASE_URL
---------------------------------

On IIS server, check: C:\inetpub\wwwroot\munshijee.ideageek.pk\.env

Should look like:
  DATABASE_URL="postgresql://postgres:YOUR_PASSWORD@localhost:5432/munshijee?schema=public"

Make sure:
  ✓ Database name is: munshijee
  ✓ Password is correct
  ✓ Host is correct (localhost if PostgreSQL is on same server)


Step 2: Check if Tables Exist
------------------------------

In DBeaver:
  1. Connect to your PostgreSQL server
  2. Expand: localhost → Databases → munshijee → Schemas → public → Tables
  3. Look for table called: User (capital U)

If you see tables like:
  - User
  - Customer
  - Invoice
  - SubscriptionPlan
  - etc.

Then tables exist! Skip to Step 3.

If NO tables exist, continue to "Create Tables" section below.


Step 3: Regenerate Prisma Client
---------------------------------

On IIS server:
  cd C:\inetpub\wwwroot\munshijee.ideageek.pk
  npx prisma generate --schema=./src/prisma/schema.prisma

Or run:
  fix-database-issue.bat

TROUBLESHOOTING
================================================================================

Issue: "database does not exist"
Fix:
  CREATE DATABASE munshijee;
  Then run dbeaver-setup.sql


Issue: "role postgres does not exist"
Fix:
  Use correct PostgreSQL username
  Update DATABASE_URL in .env


Issue: "permission denied"
Fix:
  Grant permissions:
  GRANT ALL PRIVILEGES ON DATABASE munshijee TO postgres;


Issue: "Prisma client not found"
Fix:
  npm install
  npx prisma generate --schema=./src/prisma/schema.prisma


Issue: "Connection refused"
Fix:
  - Check PostgreSQL is running
  - Check port (default 5432)
  - Check firewall


COMMON MISTAKES
================================================================================

1. Wrong database name in DATABASE_URL
   ✗ munshije (typo)
   ✓ munshijee

2. Wrong schema
   ✗ DATABASE_URL="...?schema=test"
   ✓ DATABASE_URL="...?schema=public"

3. Tables in wrong schema
   Check: SELECT table_schema, table_name FROM information_schema.tables WHERE table_name='User';
   Should be: public

4. Case sensitivity
   PostgreSQL is case-sensitive for table names
   Table must be: "User" (capital U, with quotes)
   Not: user or USER
